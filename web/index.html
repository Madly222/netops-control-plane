⚙️ Settings

⚡ Electric outage addresses

One address per line (e.g. Main Street 1). Applied live.

💧 Water outage pattern (water provider)

Regex matched against water provider (e.g. Main Street\s*,?\s*71). Applied live.

⏱️ Daily check time

Time of day the outage checks run (server local time). Applied within a minute — no restart needed.

🔄 Auto connection-check

How often the dashboard automatically re-probes server connections. Applied on next dashboard load.

🌐 DNS test zone

Zone used by the DNS health check (SOA lookup against the server's own listening IP). Must be a zone your DNS servers are authoritative for, or healthy servers will show a failed check.

⏳ SSH connect timeout

How long to wait for an SSH connection before marking a server unreachable (3–120 sec). Applied live — no restart. Raise it only for hosts with a slow sshd handshake; a high value makes dead servers slower to detect.

📧 Notification email

SMTP server and recipients for outage alerts. Applied live.
